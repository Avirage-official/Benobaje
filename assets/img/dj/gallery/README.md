# DJ page gallery: "Behind the decks"

Upload photos straight into this folder. **Any file name works.** They all
show up in the "Behind the decks" gallery on the DJ page, in name order.

- JPG, PNG or WebP. Keep each under ~500 KB (long edge ~2000px).
- Want a set order? Start names with numbers: `01-marquee.jpg`, `02-zouk.jpg` …
- Make sure you're **inside `assets/img/dj/gallery/`** when you click
  "Add file → Upload files", or the photos land in the wrong folder.

Until this folder has photos, the gallery shows the homepage photos.
