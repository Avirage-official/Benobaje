# Events page gallery: "From the floor"

Upload photos straight into this folder. **Any file name works.** They all
show up in the "From the floor" gallery on the Events page, in name order.

- JPG, PNG or WebP. Keep each under ~500 KB (long edge ~2000px).
- Want a set order? Start names with numbers: `01-senter-gates.jpg` …
- Open **this exact folder** on GitHub before "Add file → Upload files".
