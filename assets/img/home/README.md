# Homepage images — `assets/img/home/`

Drop files here with these **exact names**. Each one replaces its
placeholder automatically — no code changes. Until a file is here, the
homepage falls back to an existing photo, so nothing ever looks broken.

| File | Where it shows | Shape · size | What to shoot / pick |
|---|---|---|---|
| `hero.jpg` | Hero — the big photo beside AFRO / JUNIOR | Portrait 4:5 · 1600×2000 | Your signature shot. Face in the top third (it's cropped from the top). Strong, simple background — the type sits over it. |
| `role-music.jpg` | Hover preview on **Music** | Portrait 4:5 · 1200×1500 | Studio: at the desk, keys, headphones, session moment. |
| `role-dj.jpg` | Hover preview on **DJ** | Portrait 4:5 · 1200×1500 | Behind the decks, crowd or lights visible. |
| `role-events.jpg` | Hover preview on **Events** | Portrait 4:5 · 1200×1500 | Festival / backstage / production — stage, crew, rigging. |
| `role-creative.jpg` | Hover preview on **Creative** | Portrait 4:5 · 1200×1500 | Brand or campaign work — set, shoot, launch. |
| `og.jpg` | Link preview on WhatsApp, Instagram DMs, LinkedIn… | Landscape · 1200×630 | Name + photo. Keep key content centred. |

**Optional video:** any role can use a short loop instead of a still — name
it `role-music.mp4`, `role-dj.mp4`, etc. A video wins over a `.jpg` of the
same name. Keep loops 3–6 s, silent, 720×900, under ~3 MB.

**Export:** JPG, sRGB, quality ~80, under ~500 KB each.

**Falls back to (for now):** hero → `assets/img/hero.jpg` · music →
`assets/img/hero.jpg` · DJ → `assets/video/showreel.mp4` · events →
`assets/img/work/senter-hero.jpg` · creative → `assets/img/work/remy-hero.jpg`.
