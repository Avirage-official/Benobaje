# Music page images: `assets/img/music/`

Drop files here with these **exact names**. Each one shows up on the Music
page automatically, no code changes. Anything missing falls back to a
homepage photo (or is simply hidden), so nothing looks broken.

## Record sleeve (hero)

| File | Where | Size | Tip |
|---|---|---|---|
| `cover.jpg` | The record sleeve **and** the spinning label in the hero | Square 1:1 · 1600×1600 | Your best performance or press shot. Treat it like single artwork. |

## Camera roll (gallery)

Upload as many photos as you like into **`assets/img/music/gallery/`**.
Any file name works; they show in name order. See the README in that folder.
Until the folder has photos, the gallery shows the homepage photos.

**Export:** sRGB, quality ~80, under ~500 KB each (long edge ~2000px is plenty).
