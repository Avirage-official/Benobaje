# Music page gallery

Upload photos straight into this folder. **Any file name works.** They all
show up in the "Camera roll" on the Music page, in name order.

- JPG, PNG or WebP. Keep each under ~500 KB (long edge ~2000px).
- Want a set order? Start names with numbers: `01-marquee.jpg`, `02-zouk.jpg` …
- To remove a photo, delete it here.

New uploads appear a minute or so after the site redeploys.
